# Leçons héritées de LOT_013 (à appliquer dès le premier jet)

1. Corpus AIPS : le XML ne contient que noms de spécialités, numéros Swissmedic et URL ; une DCI peut manquer au XML et figurer dans le document lié. Chercher par nom de spécialité ET lire le document lié avant toute conclusion « absent du corpus ».
2. GesG ZH (LS 810.1) : citer la version en vigueur n° 131 (dès le 01.01.2026), PDF officiel zh.ch ; la version du 01.07.2023 est abrogée.
3. Toute norme datée postérieure au jour de rédaction s'écrit « entrera en vigueur le … », avec le droit applicable aujourd'hui.
4. Aucune abréviation développée de mémoire : nom officiel lu à la source.
5. Ne pas citer une source américaine exclusive comme référence (Prompt V0 §13.1).
6. Aucune mention interne dans les HTML (audit, HELP, correction n°, Prompt, chemins de fichiers, « python »).
7. Viser 100–125 Ko au premier jet : les audits ajoutent 5–15 Ko ; le plafond est 150 000 octets.
8. Travailler dans un sous-dossier dédié du scratchpad (`scratchpad/<LOT>_<DX>/`) : le scratchpad est partagé entre agents.
9. La classification cause / manière / circonstance (SGRM 2009 §3.2.5 ; IRM-UZH 2026 §4.2–4.3) vaut pour tout décès : une chute ancienne avec suites tardives = non naturelle.
