# Schémas interactifs — LOT_174

Trois descriptions passées par `dessinateur.rendre()` (`_travail/illustrer.py`).

- `uterus.json` — poche fermée, membranes rompues, petit fœtus
- `doppler.json` — artère ombilicale, artère cérébrale, ductus veineux
- `poumon.json` — alvéole ouverte, alvéole fermée, après surfactant (poractant alfa, AIPS 51886)

La page HTML se régénère avec `python3 grok-LOTS-html/LOT_174/_travail/illustrer.py`. Le vérificateur d'exemple du dessinateur exige des chaînes propres à la dissection aortique (faux chenal, Radiopaedia, 2014, 2020, 2022). Ces cinq marques sont écartées. Le reste du contrôle (géométrie, pastilles, repère D, trois niveaux) est vert.

Captures headless relues : `captures/uterus.png`, `doppler.png`, `poumon.png`, et le deuxième niveau `*-niveau2.png`. Pastilles sur les formes, légendes entières, texte non coupé. Le bouton du deuxième niveau change bien le dessin.
