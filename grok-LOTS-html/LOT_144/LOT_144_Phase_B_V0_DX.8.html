Taille : en cours de mesure

F1.15 · DX.8 · Encéphalopathie hépatique

L'essentiel

AIPS (information professionnelle suisse du corpus local) est le sens utilisé ici. CAT (conduite à tenir) est le sens utilisé ici. TDM (tomodensitométrie) est le sens utilisé ici. EEG (électroencéphalogramme) est le sens utilisé ici. IRM (imagerie par résonance magnétique) est le sens utilisé ici. FOUR (score de réactivité en quatre volets, utilisable si la personne est intubée) est le sens utilisé ici. AVC (accident vasculaire cérébral) est le sens utilisé ici. HSA (hémorragie sous-arachnoïdienne) est le sens utilisé ici. SSP (situation du référentiel suisse) est le sens utilisé ici. Foie malade et conscience basse. On cherche le facteur. L'ammoniaque seul ne titre pas le soin. La surrénale se discute.
