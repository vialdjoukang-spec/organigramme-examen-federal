4 · Preuve mathématique

Notation. Leçons ℓ ∈ {A, 1…10}. Une passe de modèle m (prix relatif πm, effort e) lit un paquet Ip, d'autres entrées Io, produit O jetons, en T tours. τ = octets par jeton, ρ = prix de sortie/entrée, θe = jetons de raisonnement par tour, o = amorçage du run. Cache : ε = hδ + (1−h) dans un run (h = part servie, δ = prix d'un jeton en cache), φ = hxδ + (1−hx) entre runs (S2 seulement ; φ = 1 pour S0 et S1). Valeurs de base : ε = 0,37, φ = 0,685.

Lemme 1 — coût d'une passe

$$K=\frac{\pi_m}{10^6}\Big[\varphi\,I_p+I_o+o+(T-1)\,\varepsilon\,\big(I_p+I_o+\tfrac{O}{2}\big)+\rho\,(O+\theta_e T)\Big]\tag{1}$$

K est affine, à coefficients positifs, en (Ip, Io, O) : K(E[B]) = E[K(B)] pour les tailles aléatoires B.

Lemme 2 — forme close de E[C]

Le coût d'un LOT est une somme de termes K multipliés par des indicateurs indépendants (relance Rℓ, ré-audit Aℓ, défaut de forme Mℓ, couverture par la porte Cℓ, détection Dℓ, second audit Ψℓ), chacun intervenant au plus une fois par terme. Par indépendance E[∏ 1j] = ∏ Pj ; par le Lemme 1 on remplace les tailles par leurs moyennes :

$$E[C]=\sum_{\ell}\Big[(1+r_\ell)K^{R}_\ell+(1+a)K^{M}_\ell+(1+c_S)K^{C}_\ell+\mu^{S}_\ell\Big]+K^{T}+K^{\text{méca}}_S+\kappa^{\text{cur}}_S\tag{2}$$ $$\mu^{S1}=q_1\,d_C\,\big(c_{in}+\psi K_{part}\big),\qquad \mu^{S2}=q_2\Big[\kappa K_{pa}+(1-\kappa)(d_C-\Delta_\ell)\big(c_{in}+\psi K_{part}\big)\Big]+f\,K_{pa}$$

avec q1 = qM(1−s), q2 = qM(1−vM)(1−s)(1+πpen) (probabilité d'un défaut de forme après auto-contrôle ; vM : effet de la base ; πpen : perte de fidélité du squelette), κ = couverture de la porte, Δℓ = perte de détection de la conformité légère, f = faux ROUGE, Kpa = patch isolé, cin = patch dans le run de conformité, Kpart = ré-audit partiel. S0 est (2) avec π = π47 partout, contextes complets, sans auto-contrôle. S1 : cS = 0, pas de κcur.

Vérification numérique. La même fonction lot_cout sert au Monte-Carlo (indicateurs tirés au sort) et à la forme close (probabilités). Écart forme close − Monte-Carlo, en erreurs-types : S0 -0,15, S1 -1,43, S2 -0,48 (20 000 tirages) — le Lemme 2 est vérifié, mais cela ne valide que l'algèbre, pas les hypothèses. E[C] = 71,1 (S0) ; 24,9 (S1) ; 19,6 (S2) u par LOT.
Théorème 1 (décomposition exacte). En ajoutant les composantes de S2 à S1 dans l'ordre porte, paquet, cache, légère, base, script, la différence se télescope : $$\Delta=E[C_{S1}]-E[C_{S2}]=G_{\text{porte}}+G_{\text{paquet}}+G_{\text{cache}}+G_{\text{légère}}+G_{\text{base}}+G_{\text{script}}=5,25\ \text{u}$$ chaque Gj étant calculé par (2) (tableau §2). Les pertes (faux ROUGE, relance de la conformité légère, curation, patchs de la porte) sont incluses dans les Gj : ce sont des gains nets.
Théorème 2 (le paquet gagne dès que S1 lit plus de 7 % du modèle). Au premier ordre, $$G_{\text{paquet}}\approx\frac{\pi_{47}}{10^6}\,\big[1+(T_R-1)\varepsilon\big]\Big(\sum_\ell 1+r_\ell\Big)\frac{\Delta I_R}{\tau},\qquad \Delta I_R=f_{\text{modèle}}\cdot 259\,493-18\,440\ \text{o}$$ (octets mesurés : modèle + feuille de style = 259 493 o ; paquet S2 du rédacteur = 72 536 o contre 54 096 o de lecture S1 hors modèle). Donc Gpaquet > 0 ⇔ fmodèle > 0,071. À f = 0,8 : ΔIR = 189 Ko ; la formule donne 3,46 u contre 3,48 u exacts.
Théorème 3 (conditions pour E[CS2] < E[CS1]). Avec Δ = ΣGj :
  1. (C1) fmodèle > 0,071 ⇒ Gpaquet > 0.
  2. (C2) hx ≥ 0 ⇒ 0 ≤ Gcache ≤ 0,42 u (borne atteinte pour hx = 1, δ = 0).
  3. (C3) Glégère > 0 ⇔ prelance < Khigh/Klow − 1 ≈ 0,175 (même prix π45, seul le raisonnement diffère).
  4. (C4) porte : gain net > 0 tant que ffaux ROUGE < 0,97 ; la seule capture précoce est rentable en jetons ⇔ ψ > 0,37.
  5. (C5) base : Gbase > 0 ⇔ la base obtient ≥ 16 % des effets supposés (vM, vg, vr) ; sinon perte ≤ 0,04 u/LOT.
Vérification directe du pire cas. Avec tous les paramètres défavorables à S2 en même temps (coin « pire cas » du §5 : faux ROUGE 25 %, relance de la conformité légère 35 %, perte de fidélité du squelette 60 %, base sans effet, aucun cache entre runs, ψ = 0,1, κ = 0,6, qM = 0,15, curation 100 000 jetons, etc. ; seul fmodèle varie), le calcul direct de (2) donne Δ > 0 ⇔ fmodèle > 0,039. Les composantes hors paquet, calculées une à une dans ce pire cas, totalisent +0,26 u (effets non parfaitement additifs ; la racine vient de (2), pas d'une somme). Preuve : Théorèmes 1 et 2 pour le signe du terme dominant, bornes de (C2)–(C5) et racine calculées avec (2) ; valeurs dans resultats.json › preuve_nombres.

6 · Pourquoi pas de regroupement des DD

Un DD V8 pèse ≈ 56 000 jetons de sortie (178 Ko). Chaque DD ajouté à un run alourdit le contexte porté pendant tous les tours suivants (coût ≈ quadratique) et corrèle les erreurs. Il ne reste qu'un gain : amortir l'amorçage du run et le paquet, déjà petits.

ParamètreBaseRegrouper 2 DD rapporte si…
tau_k0,60tau_k < 0,35
o_run15 000o_run > 194 045
h_in0,70h_in > 0,99

Le regroupement par 2 ne rapporterait que si chaque DD ajouté coûte moins de 35 % de tours en plus (hypothèse : 60 %) ou si l'amorçage d'un run dépasse ≈ 194 000 jetons (hypothèse : 15 000). Les deux se mesurent avec couts.py après 3 LOTS ; décision révisable (ADR-003).

7 · Limites, pertes et ce que la simulation ne dit pas

Pertes de S2, déjà dans les chiffres

  • Patchs déclenchés par la porte, faux ROUGE, relance de la conformité légère, curation de la base : 0,24 + 0,07 + 0,12 + 0,04 ≈ 0,47 u/LOT.
  • Un saut de plus dans le circuit (porte, lecture du verdict par Tunder) : +30 s par passe (hypothèse). Latence du LOT inchangée (6,2 → 6,1 h ; temps-agent 11,7 → 11,1 h). S2 n'accélère pas la production.
  • Le squelette du modèle est un résumé : risque de perdre un détail du format V8 (πpen = 20 %, plage 0–60 %).
  • Quatre scripts et une base à entretenir ; la base gonfle si personne ne l'élague (budget 8 Ko, vault_lint.py).

Limites de l'étude

  • Prix et jetons = hypothèses. Barème 4.7 = 1 ; 4.6 = 0,6 ; 4.5 = 0,25 ; sortie = 5 × entrée ; cache = 0,1. Aucune facture lue ; les rapports comptent, pas les unités.
  • Les nombres de défauts et de passes viennent de Claude (LOT_013–016, format V0). Leur transfert à Grok est supposé (± 40 %).
  • Le cache dépend du fournisseur ; S2 fonctionne sans (Gcache ≤ 0,42 u).
  • Le Monte-Carlo et la forme close sont le même modèle : ils se confirment, ils ne valident pas la réalité.
  • La porte ne juge jamais l'exactitude médicale ; elle est différentielle par rapport à MODELE_DD_V8.html parce que le harnais V0 donne de faux critiques sur le V8 (title 653, bande, externe, h2, h3_14). Si le modèle change, relancer porte_zero_jeton.py reference.
  • Incohérence à trancher : la règle de clôture « controle_lot = 0 critique » est impossible en V8 (66 critiques sur LOT_016 V8).
  • Parallélisme (5 runs), vitesses de génération et tours par run : hypothèses ; seul le temps-agent relatif S1/S2 est exploitable.
