# Liste DX canonique — LOT_187 O2.5

Retard du développement.
L'ordre DX suit la place du diagnostic dans le motif : fréquence d'abord pour les tableaux du cabinet, gravité ensuite pour les formes plus rares. Aucune incidence suisse unique ne classe les dix lignes. Le langage isolé est le motif parental le plus habituel. Les rangs E sont l'ordre d'exclusion des dangers, pas l'ordre des fichiers.
