L'essentiel

AIPS (information professionnelle suisse du corpus local) est le sens utilisé ici. ORL (oto-rhino-laryngologie) est le sens utilisé ici. CAT (conduite à tenir) est le sens utilisé ici. EFP (fédération européenne de parodontologie) est le sens utilisé ici. VADS (voies aérodigestives supérieures) est le sens utilisé ici. ISPAD (société internationale de diabétologie pédiatrique et de l'adolescent) est le sens utilisé ici. HUG (hôpitaux universitaires de Genève) est le sens utilisé ici. CSV (composés soufrés volatils) est le sens utilisé ici. INR (rapport international normalisé) est le sens utilisé ici. TN1 (besoin d'explication et d'hygiène, langue comprise) est le sens utilisé ici. TN2 (besoin de soins buccaux quand une maladie buccale est là) est le sens utilisé ici. TN3 (besoin d'un médecin ou d'un spécialiste) est le sens utilisé ici. TN4 (besoin de réassurance quand aucune odeur n'est perçue) est le sens utilisé ici. TN5 (besoin d'un psychologue ou d'un psychiatre si la conviction demeure) est le sens utilisé ici. Personne ne sent l'odeur. On explique et on rassure. Si la conviction tient, on n'ajoute pas un détartrage.

Deux juges cotent zéro. Le frère ne confirme pas. La personne accepte d'arrêter les rinçages.1
