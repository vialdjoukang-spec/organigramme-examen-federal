# Incertitudes retirées du cours — LOT_155

Cinq retraits. Le texte du cours ne contient pas ces éléments.

1. Aucun texte lu ne classe les dix diagnostics par prévalence suisse. Le rang E de la leçon est l'ordre de l'algorithme, pas une fréquence.
2. ~~Insuline avec glucose et salbutamol nébulisé dans l'hyperkaliémie~~ complété le 2026-10-31, source UK Kidney Association, octobre 2023 : recommandés (insuline-glucose dès 6,5 mmol/l, suggérés entre 6,0 et 6,4 ; salbutamol adjuvant si sévère), fiche du point 4. Les unités et les milligrammes restent retirés : absents de l'information professionnelle suisse lue. Glucocorticoïde, alfacalcidol et calcitriol : restent retirés, même motif.
3. Borne chiffrée de l'hyperphosphatémie : le texte de 2019 sur l'hypophosphatémie ne la donne pas. La leçon décrit le mécanisme de rétention sans inventer un seuil.
4. ~~Signes de Chvostek et de Trousseau~~ complété le 2026-10-31, source Cooper et Gittoes, BMJ 2008 : percussion du facial ; brassard ; 10 % de faux positifs pour Chvostek, 94 % contre 1 % pour Trousseau.
5. ~~Lyse tumorale~~ complété le 2026-10-31, source Cairo et Bishop, Br J Haematol 2004 : au moins deux anomalies (acide urique, potassium, phosphate, calcium) dans la fenêtre de trois jours avant à sept jours après le traitement.

Faux positif possible du script de certitude, non modifié : une vitesse écrite « ml par heure » évite le motif `ml/h`, qui exigerait une phrase AIPS même pour un débit lu dans un guide européen. Le débit de calcium de la Society for Endocrinology 2016 est donc écrit en toutes lettres.
