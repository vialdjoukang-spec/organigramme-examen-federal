# Incertitudes — LOT_186 — O2.4 Vaccination de l’enfant

Aucun élément central retiré. Les seuils, les schémas entiers lus et les doses AIPS restent dans le cours.

1. Nouveau-né de mère porteuse de l’antigène de surface : la note du plan 2026 décrit quatre doses à 0, 1, 2 et 12 mois. La même page écrit aussi qu’une dose prévue à 4 mois peut se faire avec un vaccin pentavalent. Le cours garde les quatre doses de la note comme schéma indispensable et ne transforme pas cette phrase en cinquième dose obligatoire.
2. Délai après immunoglobulines ou produit sanguin : le plan 2026 écrit au moins cinq mois pour les vaccins rougeole-oreillons-rubéole-varicelle, délai selon la dose d’immunoglobulines. L’information 58158 écrit au moins trois mois. Les deux phrases sont dans le cours. Quand les deux s’appliquent, le délai le plus long lu est celui du plan.
3. Immunoglobulines antitétaniques : le plan 2026 dit quand les donner, sans dose en milligrammes dans l’extrait archivé. Aucune information professionnelle d’immunoglobuline n’a été extraite ici, donc le cours n’écrit pas de dose chiffrée d’immunoglobulines.
4. Rage : le plan 2026 écrit un maximum de vingt unités internationales par kilogramme et un lavage de quinze minutes. Le schéma exact jour par jour selon le statut vaccinal n’a pas été recopié ligne à ligne depuis l’encadré mal extrait du PDF. Le cours dit que le schéma dépend d’au moins deux doses antérieures, sans inventer les jours manquants.
5. Obligations cantonales de vaccination scolaire : non lues. Le cours ne dit ni qu’un vaccin est obligatoire ni qu’il est libre dans un canton.
