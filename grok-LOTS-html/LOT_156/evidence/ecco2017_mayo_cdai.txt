1. ECCO, Third evidence-based consensus on ulcerative colitis, part 2, J Crohns Colitis 2017. DOI 10.1093/ecco-jcc/jjx009.
« Patients with bloody stool frequency ≥ 6/day and a tachycardia (> 90 min-1), or temperature > 37.8°C, or anaemia (haemoglobin < 10.5 g/dl), or an elevated ESR (> 30 mm/h) have severe UC. Only one additional criterion in addition to the bloody stool frequency ≥ 6/day is needed. In practice, a CRP of 30 mg/l can be substituted for the ESR. »

2. ECCO part 1, DOI 10.1093/ecco-jcc/jjx008, tableau du score de Mayo :
Stool frequency: normal ; 1–2/day > normal ; 3–4/day > normal ; ≥5/day > normal.
Rectal bleeding: none ; streaks ; obvious ; mostly blood.
Mucosa: normal ; mild friability ; moderate friability ; spontaneous bleeding.
Physician’s global assessment: normal ; mild ; moderate ; severe.
Le score original est celui de Schroeder KW, Tremaine WJ, Ilstrup DM, N Engl J Med 1987;317:1625-1629. Le texte intégral de 1987 n'a pas été ouvert ; le tableau lu est celui de l'ECCO.
