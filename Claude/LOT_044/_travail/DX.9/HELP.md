# HELP DX.9 — lacunes à traiter par le chef de production
- Lidocaïne (anesthésie locale avant drain thoracique) : aucune spécialité injectable à usage d'infiltration lisible dans l'AIPS (Xylocain 52094 = gel urologique, 52097 = spray) ; classe et principe cités sans milligramme.
- Oxygène et AINS : pas de fiche AIPS pertinente ; oxygène cité sans débit, AINS non cités.
- Aucune recommandation d'une société suisse (SSP, SSPO) ni donnée OFS/Obsan sur le pneumothorax spontané lue ; la Revue Médicale Suisse 2023 (Humair, Daccord, Lazor) sert de référence suisse.
- Assurances et certificat d'incapacité : aucune source suisse lue ; seul l'aspect aptitude (plongée, aviation) est traité.
- Pédiatrie : la recommandation ERS/EACTS/ESTS 2024 vise l'adulte ; aucune source pédiatrique lue.
- Divergence à arbitrer : délai de vol 7 jours après résolution radiologique (ERS 2024) vs 3 mois (RMG 2012) ; le cours retient ERS 2024.
- Échec réseau : publications.ersnet.org (403) ; texte ERS lu via air.unimi.it.

## Après audit P3 (correction)
- Lidocaïne : AIPS Lidocaïne Streuli 30015 utilisée (Rapidocain 32381 absent du paquet) ; Xylocain 52094 (gel urétral) retiré.
- Morphine : numéro corrigé 56560 (solution injectable).
- Non traités : source européenne récente pour le site de décompression à l'aiguille (RMG 2012 conservée) ; adaptation rénale du paracétamol (aips-47503-8).
