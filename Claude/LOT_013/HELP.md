# LOT_013 — HELP (lacunes de sources, hors cours)

Registre des lacunes retirées des leçons lors du renfort L1 du 10.11.2026. Aucune de ces formules ne figure plus dans un cours.

## Phase A
- Fréquence suisse des décès en lien avec un acte médical (DX.9) et des décès de nature indéterminée (DX.10) : aucune donnée chiffrée dans les sources lues le 30.10.2026.
- Consensus SGRM/SSML « Legalinspektion » du 26.06.2009 : aucune version plus récente trouvée le 30.10.2026 ; vérifier une éventuelle révision.
- Code de déontologie de la FMH, article sur les certificats : accès refusé le 30.10.2026, article non lu.
- Prévention de l'intoxication au CO liée aux appareils à combustion : recommandation suisse non trouvée.
- Décès inattendu du nourrisson : aucune recommandation suisse spécifique trouvée ; la HAS (France, 2007) sert de référence européenne.
- Valeur diagnostique (sensibilité, spécificité) des signes de l'examen externe et de l'absence de pétéchies : non chiffrée dans les sources lues.
- Activité médico-légale romande (CURML) : 2018 est la dernière année trouvée.

## DX.1 — Suicide assisté
- Répartition cantonale des suicides assistés et coût : non chiffrés dans les sources lues.
- Données européennes comparatives : non reprises.
- Sensibilité et spécificité de l'évaluation clinique de la capacité et de l'examen externe : non publiées dans les sources lues.
- Seuil toxicologique propre au suicide assisté : non fixé dans les sources lues.
- Personne qui respire encore sous barbiturique : aucune source spécifique ; conduite déduite de l'ASSM et du CC.
- Médecin prescripteur appelé au constat : aucune règle suisse explicite lue.
- Pentobarbital : aucune information humaine sur contre-indications, interactions, insuffisance hépatique ou rénale ; mineur et femme enceinte : aucune source suisse lue.
- Personne domiciliée à l'étranger : aucune règle particulière de constat trouvée.

## DX.2 — Chute accidentelle de la personne âgée
- Sensibilité et spécificité des signes externes et de l'examen médico-légal : non chiffrées dans les sources lues.
- Recommandation suisse sur l'indication du CT cérébral chez le chuteur vivant sous anticoagulant : non trouvée (NICE NG232 utilisée).
- Critères suisses de retour à domicile après une chute : non trouvés (NICE NG232 utilisée).
- Complications de l'immobilisation (pneumonie, thrombose, escarres) : non chiffrées dans les sources suisses lues.
- Série suisse récente de mortalité absolue après fracture du fémur proximal (après SwissDRG) : non trouvée le 30.10.2026.
- Différence régionale chiffrée des chutes (ESS) : non trouvée ; stratégie chirurgicale de la fracture cervicale : hors sources lues.
- Code de déontologie FMH, article sur les certificats : accès refusé.
- Image candidate (point 9) : PMCT d'un hématome sous-dural ; non insérée faute de marge sous 150 Ko.
