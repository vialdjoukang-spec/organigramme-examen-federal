# HELP DX.10 — Cancer de l'ovaire (LOT 054)

AIPS : les cinq DCI de la ligne DX.10 ont un AIPS lisible dans le corpus (carboplatine : 54829, 58289, 66717, 47671 ; paclitaxel : 56990, 58445, 60228, 70648 ; olaparib : 66745 ; niraparib : 68652 ; bévacizumab : 67886). Aucune molécule déclarée sans AIPS.

Lacunes de sources (non écrites dans le cours, car non lues) :
- Texte intégral ESGO-ESMO-ESP 2024 et ESGO/ISUOG/IOTA/ESGE 2021 : seuls les résumés PubMed sont lisibles (Elsevier, Wiley, OUP renvoient 403/captcha). Les recommandations chirurgicales fines (chirurgie d'intervalle, chimiothérapie néoadjuvante, HIPEC, chirurgie de rechute, tumeurs borderline, grossesse) ne sont donc pas détaillées.
- Dose de carboplatine en association avec le paclitaxel (AUC cible) : l'AIPS lu donne l'AUC en monothérapie et avec le cyclophosphamide, pas pour carboplatine + paclitaxel.
- Gemcitabine, doxorubicine liposomale, cisplatine (AIPS non cherchés : hors ligne DCI) pour la récidive.
- Surveillance après traitement (CA125, imagerie), critères de sortie, fertilité, hormonothérapie substitutive : aucune source lue.
- Technique de l'examen gynécologique (toucher vaginal, percussion de l'ascite) : aucune source lue.
- Remboursement LAMal des inhibiteurs de PARP et limitations OFSP, assurances sociales : aucune source lue.
- Contrastes iodés, IRM et TEP : aucune source lue pour la stadification.
