# HELP — DX.8 Cancer du rein (carcinome à cellules rénales)

Molécules : toutes les DCI de la ligne DX.8 ont un AIPS lu dans le corpus (aucune absente).
- pembrolizumab : Keytruda 66231 (et sous-cutané 70253), nivolumab : Opdivo 65660 (sous-cutané 70192), ipilimumab : Yervoy 61798.
- axitinib : Inlyta 62281 (génériques Sandoz 69472, Spirig 69290), cabozantinib : Cabometyx 66471, lenvatinib : Kisplyx 66085 (Lenvima 65512 pour d'autres indications).
- Ajouts hors liste DCI : bélutifan Welireg 68531, pazopanib Votrient 60326, sunitinib (génériques Viatris 68094, Teva 67781 ; pas de spécialité d'origine trouvée dans le corpus).

Lacunes de sources (aucune formule de lacune dans le cours) :
1. ESMO RCC 2024 (Powles, Ann Oncol 35:692) : texte intégral inaccessible (annalsofoncology.org renvoie 403). Seule la notice PubMed a été lue ; la conduite enseignée repose sur l'EAU (uroweb, lu le 2026-11-10) et sur l'AIPS. L'année de l'édition EAU consultée n'apparaît pas dans les extraits.
2. Volet social et assurances (LAMal, garantie de prise en charge des traitements hors liste, incapacité de travail) : aucune source suisse lue ; seul le volet psychosocial (enquête IKCC citée par l'EAU) figure dans le cours.
3. Recommandation suisse de dépistage ou de prévention propre au cancer du rein : aucune lue (OFS 2021, Ligue contre le cancer et Revue Médicale Suisse 2018 sont les sources suisses). La prévention s'appuie sur l'EAU et le code européen contre le cancer.
4. Critères de sortie de suivi : l'EAU ne les définit pas ; le cours expose la logique du risque concurrent de décès (RECUR) et le calendrier de l'EAU.
5. Divergences EAU / AIPS notées : l'AIPS Inlyta et ses génériques limitent l'indication à l'échec d'un traitement systémique préalable, alors que l'AIPS Keytruda mentionne l'association axitinib en première ligne ; Cabometyx + nivolumab, Opdivo + ipilimumab et Kisplyx + pembrolizumab sont limités par l'AIPS au risque IMDC intermédiaire ou défavorable, alors que l'EAU admet le risque favorable (recommandation faible). Le cours suit l'AIPS.
6. Cliché de référence (point 9) : aucune image sous licence ouverte inspectée ; le cours renvoie aux figures de l'article de la Revue Médicale Suisse 2018 sans les copier.
7. Chiffres Ligue contre le cancer pour le rein : notes de bas de page ambiguës (« 8504 »), non utilisés ; les chiffres suisses viennent du rapport OFS 2021.
