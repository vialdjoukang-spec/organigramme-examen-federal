# HELP DX.6 — lacunes de sources (LOT_047, S2.8, maladie ulcéreuse gastroduodénale)
- Épidémiologie suisse : aucune prévalence suisse de l'ulcère lue ; chiffres WSES, OCDE, Finlande ; seules données suisses : éradication à Zurich (Swiss Med Wkly 2023).
- Maastricht VI : résumé PubMed seul (texte intégral hors PMC) ; schémas d'éradication de première ligne non lus en détail ; PDF SMW 2025 (Hp-EuReg Suisse) illisible.
- Examen physique : aucune source lue ne décrit la technique des gestes (palpation, défense, toucher rectal) ; point 6 limité aux paramètres cités par WSES.
- Valeurs normales SI, grossesse, enfant, DFGe < 30, allergie à l'iode, IRM impossible pour les examens du point 9 : aucune source lue ; seules les notices AIPS donnent grossesse et enfant pour les médicaments.
- Métronidazole : aucune monopréparation AIPS lue avec indication H. pylori ; doses citées d'après les schémas des IPP (Pantoprazol-Mepha Teva 59834). Tétracycline seule : aucune monopréparation pertinente (Pylera 66366 cité).
- Amoxicilline Sandoz (56203) : durée 10–14 jours, divergente de 7 jours (IPP) et de 14 jours (WSES) ; AIPS suivi.
- Aspects social et assurances (11.B) : aucune source lue ; non rédigés. Recommandation suisse officielle de prévention : non lue.
- Antibiotiques de la perforation (WSES) : classe sans milligramme (pas d'AIPS lu).
- ESGE 2021 texte intégral non lu (résumé PubMed) ; ESGE 2026 : résumé seul.
