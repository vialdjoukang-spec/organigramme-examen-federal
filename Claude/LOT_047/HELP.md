# Lacunes ouvertes

- Phase A et DX.1 : pas d'enquête de population suisse lue pour la prévalence du reflux ; les chiffres gardés sont européens ou mondiaux (Revue Médicale Suisse 2026, méta-analyses).
- DX.1, point 6 : aucun signe physique propre au reflux dans les sources lues ; l'examen sert à écarter l'urgence et les autres causes.
- Phase A et DX.1 : alginates, famotidine et hydrotalcite sans monopréparation AIPS lue ; aucune dose en milligrammes n'est écrite pour ces classes.
- Phase A : clopidogrel, amoxicilline, clarithromycine, antidépresseur tricyclique, vonoprazan et corticoïde topique sans dose, faute d'information professionnelle de ces molécules dans ce lot.
- DX.1 : la dose double d'ésoméprazole n'est pas dans l'AIPS d'Esomep® (60574) ; elle n'est pas enseignée.
- Schéma du péristaltisme : les légendes du fichier sont en kurde ; la lecture française est dans la fenêtre. Référence non vérifiée pour cette fiche quant au sens de chaque mot kurde hors gorge, estomac et bol.
- Légionnaire (Grammalecte) : alertes bloquantes jugées fausses, phrases non tordues — noms de médicaments (ésoméprazole, lansoprazole, rabéprazole, oméprazole, magaldrate, pylori, clopidogrel), « œsogastrique », « antisécrétoire », « melaena », « globus », « endoscopiés », « épidermoïde », « bisphosphonates », sigles de revues (Rev Med, Dig Dis Sci), noms de fichiers d'images, « Ne rang », accords sur « DX.4 » à « DX.10 », lettres « 9.b / 9.c / 9.d », dérivations V2 V3 V4. Le script signale aussi à tort les 🚩.
