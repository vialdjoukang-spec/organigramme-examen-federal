# HELP DX.4 — lacunes de sources (rédaction)

- Aucune recommandation suisse de pneumonie communautaire (SSI/SGInf, ssi.guidelines.ch, page dynamique non lisible) ni de bronchite aiguë (RMS) n'a pu être lue ; les points 8, 10, 11 s'appuient sur la recommandation ERS/ESCMID 2011 (PMC7128977), l'ERS/ESICM 2023, les cohortes suisses CAPNETZ 2026 et PHYTOBRON 2026, et l'AIPS.
- Vaccination antipneumococcique : page OFSP lue (wc90e13) ; PDF de la prise de position sur les vaccins conjugués par groupe d'âge non lu. Recommandation suisse de pneumonie (SSI/SGInf) toujours non lue.
- Valeurs normales SI (CRP, leucocytes, procalcitonine, troponine, pH pleural) : seuils CRP lus (mg/L) ; aucune valeur normale SI lue pour les autres.
- Alternatives d'imagerie en grossesse, DFGe < 30, allergie à l'iode : aucun extrait lu hors IRM/échographie (PMC11003523).
- AIPS rapatriés (2026-11-10) : azithromycine 57482, lévofloxacine 59085, moxifloxacine 63183, oseltamivir 55196, clindamycine 61556. Ibuprofène : aucune posologie AIPS pour la douleur pleurétique (dose rhumatismale citée).
- Mécanisme neuro-anatomique détaillé de la douleur pleurétique (innervation de la plèvre pariétale) : non trouvé ; seule la définition « inflammation de la plèvre pariétale » (StatPearls, résumé PubMed 32644384) est citée.
- Incapacité de travail et assurances (11.B) : aucune source suisse lue.
- Tableau genevois de probabilité d'infarctus (HUG 2007, Gaspoz 1993) : source ancienne ; chiffres repris tels quels.
- Pas de source suisse pour la pleurite virale ; revues américaines (Am Fam Physician, StatPearls) en résumé PubMed seulement.
