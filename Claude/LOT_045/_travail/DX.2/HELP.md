# HELP — DX.2 Bronchite aiguë (LOT_045)

Lacunes à combler (aucune source suisse lue sur ces points ; le texte reste qualitatif, sans chiffre) :
- Épidémiologie suisse (incidence, consultations, Sentinella/OFS/Obsan) : seules des données européennes (GRACE, registres BE/NL/SE) sont citées.
- Paracétamol : aucune information professionnelle AIPS lisible dans le paquet (Dafalgan/Panadol non retenus par le filtre DCI) ; pas de milligramme écrit.
- Amoxicilline adulte : seule la suspension pédiatrique (Co-Amoxicilline Spirig HC, 66429) est dans le paquet ; la dose adulte n'est pas écrite (NICE citée sans mg).
- Ibuprofène : l'AIPS lu (49156) ne donne pas de dose antipyrétique adulte ; dose non écrite.
- Salbutamol (Ventolin 37397) : mentionné seulement comme non recommandé hors asthme/BPCO, sans dose.
- Seuils CRP au cabinet (repères de décision) : pas de recommandation lue ; seule la valeur normale générique figure dans un tableau.
- Plan suisse de vaccination (OFSP/CFV) et stratégie StAR : non lus ; formulés sans chiffre (point 12).
- Recommandation suisse propre à la bronchite aiguë (SSI/ssi.guide, SSMIG/Forum Médical Suisse) : introuvable en accès libre ; la NICE NG120 (2019), la DEGAM (2021, résumé PubMed) et le CHEST (2020) servent de repères européens/internationaux.
- Revue Médicale Suisse 2017 (corticoïdes per os dans la bronchite aiguë) : seul le titre est lisible ; non utilisée.
- Physiopathologie (points 3 et 7) : mécanismes généraux de manuel rédigés sans chiffre ni citation, à recouper avec un traité.
