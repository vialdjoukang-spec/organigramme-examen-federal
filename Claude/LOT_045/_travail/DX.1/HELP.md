# HELP — DX.1 (LOT_045)

Lacunes à traiter par le chef de production ou un auditeur.

- Paracétamol seul : aucune information professionnelle AIPS lisible dans le paquet. Le cours le traite par classe et sans milligramme. La seule préparation retenue est Irfen Dolo comp (ibuprofène et paracétamol, Swissmedic 67815).
- Décongestionnant nasal (xylométazoline) : aucune information professionnelle AIPS lisible. Seule la limite de 5 jours de la CSS est citée, sans dose.
- Recommandation suisse de prise en charge du rhume (Revue Médicale Suisse, HUG, Forum Médical Suisse) : non retrouvée en texte intégral. Les conduites reposent sur la CSS (assureur), l'OFSP, l'information professionnelle Swissmedic et la revue Eccles 2023 (Front Allergy).
- StatPearls et NICE CKS (NBK470379, NBK459363, cks.nice.org.uk) : bloqués par reCAPTCHA ; non cités.
- Passages non chiffrés rédigés sans citation (technique d'examen, otoscopie, test streptococcique, score de Centor, urgences chronologiques, valeurs de référence des cellules de tableau CRP, leucocytes, D-dimères, saturation) : à vérifier contre une source suisse.
- Chiffre Infovac « 112 000 à 275 000 consultations » : illisible dans l'extrait (colonnes entrelacées) ; non repris.
