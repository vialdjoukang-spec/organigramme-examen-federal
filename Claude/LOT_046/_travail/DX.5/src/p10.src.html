L'algorithme suit une logique d'exclusion progressive, car le syndrome n'est retenu qu'après l'élimination des causes graves[[wbfab24-6]]. Chaque nœud ci-dessous est un signe, un examen ou une action.
  • Si la dyspnée est aiguë, alors il faut prendre l'oxymétrie de pouls[[wbfab24-6]].
    • Si la saturation est abaissée, alors une cause organique est probable[[wbfab24-7]].
    • Si la saturation est proche de 100%, alors il faut faire l'ECG et la radiographie[[wbfab24-7]].
  • Si l'ECG montre une ischémie, alors la filière coronarienne est prioritaire, même si le syndrome peut modifier le tracé[[wbfab24-7]].
  • Si la radiographie montre un foyer ou un pneumothorax, alors le diagnostic organique est retenu[[wbfab24-7]].
  • Si le NT-proBNP ou le BNP est élevé, alors l'insuffisance cardiaque doit être confirmée par l'échographie[[w149687-30]].
  • Si une embolie pulmonaire reste possible, alors un bilan par D-dimères, scintigraphie ou angiographie est nécessaire[[wbfab24-8]].
  • Si une acidose métabolique est suspectée, alors la gazométrie artérielle est indiquée[[wbfab24-8]].
  • Si ces examens sont normaux, alors il faut chercher un asthme[[wcebf5f-14]].
    • Si l'asthme est confirmé, alors il faut le traiter, et le syndrome peut coexister[[wbfab24-3]].
  • Si les causes organiques sont exclues, alors il faut chercher des arguments positifs[[w61914e-2]].
    • Si le questionnaire de Nijmegen est positif et que l'hypocapnie est présente, alors le syndrome est probable[[w61914e-2]].
    • Si les attaques sont inattendues et récurrentes, alors un trouble panique est probable[[we22718-31]].
  • Si le syndrome est retenu, alors il faut éduquer et rassurer le patient[[wbfab24-10]].
    • Si l'anxiété est intense, alors il faut proposer une thérapie cognitivo-comportementale ou un ISRS[[we22718-65]].
    • Si les symptômes persistent, alors il faut demander un avis spécialisé[[we22718-72]].
