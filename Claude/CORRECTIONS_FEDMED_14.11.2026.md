# Corrections de code — PROGRESSION__FedMed.html (fichier de Grok)

Script : `outils/corriger_fedmed.py ENTREE.html SORTIE.html`. Base : `imagerie_GROK/fedmed/sortie/PROGRESSION__FedMed.html` (branche `leona/fedmed-fenetres`), non modifiée.
Contenu inchangé : textes, images, contours, flèches, couleurs et choix de design de Grok. On ajoute seulement un bloc CSS et un bloc JS commentés (`gm-correctif-css`, `gm-correctif-js`), une fois dans le document principal et une fois dans la page embarquée du recensement (`data-emb="rts"`, réencodée à l'identique). Chaque ajout est vérifié par une assertion : il doit s'appliquer une seule fois.

Contrôle : Playwright (Chromium), 1400 px et 390 px. Les 456 fenêtres à visionneur des onglets Imagerie et Explorations ont été ouvertes une par une. Dans chacune, le script a cliqué les flèches, le zoom lié, la légende, l'anatomie, un zoom avant puis la remise à zéro, un repère, le mode défi et les indices, puis a fermé la fenêtre. Les 60 visionneurs du document principal ont été contrôlés à part.
