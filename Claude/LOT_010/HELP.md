# LOT_010 — lacunes consignées pendant le renfort L1 (10.11.2026)

Chaque entrée : fichier, point, question précise, sources déjà consultées. Rien de ce qui suit n'apparaît dans les cours.

- DX.1 (lombalgie), point 9, image : la lombalgie commune n'a aucun examen d'imagerie décisif (diagnostic clinique, HUG 2022) ; aucune image n'est donc insérée. Les clichés de causes spécifiques (queue de cheval, spondylodiscite) relèvent d'autres leçons.
- DX.1, point 5 : l'intensité et l'horaire précis de la douleur commune ne sont pas chiffrés dans les sources lues (HUG 2022, Lancet 2018) ; la fenêtre « Caractériser la douleur lombaire » s'en tient aux éléments sourcés.
- DX.2 (cervicalgie), point 9, image : la cervicalgie commune et la radiculopathie se diagnostiquent cliniquement (AFP 2016, RMS 2019) ; aucune image libre décisive n'a été insérée. Un cliché IRM de hernie cervicale (Wikimedia Commons) pourrait illustrer la 2e intention : à rechercher quand le débit Wikimedia le permet.
- DX.2, source [18] (Canton du Jura, LAI) : la version en vigueur de la LAI reste à relire sur Fedlex (mention « à vérifier » de la bibliographie d'origine conservée hors du texte du cours).
- DX.3 (céphalées), bibliographie : la source [13] groupait onze AIPS sans numéro ; chaque spécialité a reçu son entrée propre, avec le n° d'autorisation relevé dans la liste Swissmedic des médicaments autorisés (HAM). Les textes AIPS eux-mêmes n'étaient pas dans le corpus local (AipsDownload_20261008) : les doses restent celles lues le 27.10.2026 par l'auteur d'origine, à recontrôler sur swissmedicinfo.ch.
- DX.3, point 9, image : migraine et céphalée de tension se diagnostiquent cliniquement (ICHD-3) ; une TDM d'hémorragie sous-arachnoïdienne illustrerait le drapeau rouge « coup de tonnerre » (Wikimedia Commons) : à ajouter si le débit le permet.
- DX.3, point 6 : les seuils chiffrés « normal » (tension < 140/90 mmHg, température < 38 °C, force 5/5) n'avaient pas de source dans la leçon ; ils ont été remplacés par « normales » en attendant une source suisse.
- DX.4 (syndrome pariétal), bibliographie : la source [4] groupait six AIPS sans numéro ; chaque spécialité a reçu son entrée (n° HAM). Textes AIPS absents du corpus local : doses lues le 27.10.2026 par l'auteur d'origine, à recontrôler.
- DX.4, point 11 : la phrase « éviter les AINS si DFGe < 30 mL/min (KDIGO 2024, hors AIPS) » citait une source absente de la bibliographie ; elle devient « l'AIPS de l'ibuprofène contre-indique les AINS en insuffisance rénale sévère » : vérifier le libellé exact de l'AIPS Algifor Liquid Caps (n° 65372).
- DX.4, point 9, image : le diagnostic est clinique (pas de gold standard, Mott 2021) ; aucune image décisive. Un ECG de SCA ou une échographie de Tietze pourraient servir d'illustration secondaire.
- DX.4, point 6 : la fourchette « pouls 60–100/min » n'avait pas de source ; elle a été retirée du texte « normal ».
