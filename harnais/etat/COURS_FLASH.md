# Cours Flash — directive cumulée de Vial (28.10.2026, après le test unique DX.1)

Remplace le prototype volumineux (410 Ko). Le plan des 14 points reste le même ; le fond devient flash, le détail passe dans des fenêtres.

## Volume
- Bande : **100 à 250 Ko** par leçon (visé : 100–200). Notions comprises. Un prototype à 410 Ko est refusé.
- Plus de « notions voisines » en bloc dans le texte : un diagnostic différentiel utile se range dans une fenêtre cliquable.
- Rien de sourcé d'essentiel n'est perdu : ce qui est secondaire descend dans une fenêtre, ce qui est inutile est retiré.

## Contenu de chaque partie (concis, universitaire)
Situer le problème, le définir, donner les mécanismes de survenue, les liens avec symptômes et signes, la prise en charge, les démarches point par point. Phrases complètes (sujet, verbe, complément), style soutenu, termes dédiés. Rien de plus que le strict nécessaire dans le corps du texte.

## Fenêtres (obligatoires et visibles)
- Tout détail supplémentaire s'ouvre dans une **vraie fenêtre** cliquable (modale), pas seulement un survol. Survol réservé aux précisions courtes.
- **Symptômes** : listés simplement, chacun cliquable avec l'information utile.
- **Examen clinique** : énumérer simplement ce qu'il faut chercher ; chaque signe cliquable (comment le rechercher, manœuvre).
- **Syndrome** : un clic ouvre une fenêtre contenant un **tableau à 2 colonnes : symptôme | signes physiques**.
- Listes, déroulement de méthode, détails de l'algorithme : dans les fenêtres.
- La partie « Examen physique » (ingénierie d'architecture) est appréciée : même conception, mais son contenu détaillé est rabattu dans les fenêtres.
- Partie « Approche syndromique » : appréciée, à reprendre avec fenêtres, sans saturer l'îlot.

## Mise en page : îlots
- Chaque partie est un **îlot** : segment rectangulaire à bords visibles, texte **justifié** occupant la même largeur latérale partout.
- Regroupement : **parties 1, 2, 3, 4 dans le même îlot** ; **parties 5 et 6 dans une même page/îlot** ; **le reste contracté** (replié, déroulable).
- Page aérée : jamais d'îlot saturé ; peu de bruit ; pas de redites.

## Prise en charge (inchangé, en îlot)
Titre gras + bande colorée + souligné. 1- But ; 2- Moyens et méthodes : A urgences (non-spécialiste puis service spécialisé, actes cliquables), B hors urgences (mesures générales puis spécifiques, par priorité). Algorithme en cases, traits horizontaux/verticaux, mots cliquables à fenêtre.

## Exigences minimales (inchangées)
Langue universitaire ; fond médical véridique ; grille des 14 points + Prompt universel. Souplesse : un défaut sans conséquence pour l'apprentissage est un avertissement. Source non suisse admise pour l'universel ; suisse d'abord pour le local (AIPS, recommandations, filières).

## Correction et recours
Fautes critiques, graves, moyennes : marquées et consignées avec localisation (registre JSON) ; une seule tentative de correction par le professeur ; le reste part dans un tableau .md à Vial pour recours externe (autre IA).

## Circuit
Rédacteurs (duo médico-linguiste Sonnet 5.5, un par leçon) produisent le cours Flash ; professeur émérite Opus 5.5 moyen vérifie le fond ; porte unique ; 16 Sonnet + 12 Opus. Lancement : LOT_001 complet (16 fichiers).


## Principe de fiche (Vial, 28.10.2026) — Pareto
Le cours Flash est une FICHE DE LECTURE : seuls les 20 % d'information qui donnent 80 % de la compréhension restent dans le corps ; le reste est du bruit et est RETIRÉ (pas déplacé dans une fenêtre, sauf si utile à un clic). Une idée par phrase complète ; chaque sous-titre dit seulement l'essentiel de ce qu'il annonce. Progression du petit au clinique : mécanisme (physiopathologie) → symptômes et signes → prise en charge, qui découle et se justifie par le mécanisme. Page aérée : marges, titre net, séparations discrètes, jamais d'îlot saturé.
