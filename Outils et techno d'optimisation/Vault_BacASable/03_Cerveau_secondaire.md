# Cerveau secondaire

Obsidian conserve les décisions, sources, problèmes et résultats en notes Markdown reliées. Un index court permet de reprendre sans recopier l’historique dans chaque prompt.

Coût logiciel de base : 0 € pour cet usage local. Limites : organiser les notes et les sauvegardes ; ne pas y stocker de secret.
