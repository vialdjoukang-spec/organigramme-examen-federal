# Audit intégré au circuit

Ordre : scripts déterministes → tests visuels → petit modèle local pour trier → modèle expert seulement sur les cas non résolus → validation humaine des points sensibles.

Objectif : réduire la relecture externe, **pas la supprimer**. Un test vert prouve seulement ce qu’il vérifie.
