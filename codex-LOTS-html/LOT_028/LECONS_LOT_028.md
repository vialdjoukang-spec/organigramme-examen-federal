# Leçons provisoires

- Une baisse soudaine est urgente sans attendre une mesure de 30 dB.
- Le vertige avec hypoacousie peut être vasculaire.
- Les délais d’épanchement pédiatrique ne se transposent pas à l’adulte.
- L’hyperacousie demande un accompagnement tolérable, pas une exposition forcée.
- Les résultats partiels et les liens futurs restent déclarés incomplets.
