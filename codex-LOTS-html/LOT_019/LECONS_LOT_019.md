# Leçons pour LOT_020

Utiliser verifier_lot_generique_v8.py avec le dossier exact ; ne pas réutiliser les titres, diagnostics ni sources du lot précédent. Mesurer chaque HTML individuellement. Conserver les rapports historiques négatifs lorsqu’ils appliquent des règles antérieures à V8, avec analyse explicite.

Consigner les passes avec Phase_A et DX.N, clés attendues par la veille. Une source institutionnelle peut contenir une formulation anatomique trop générale : recouper en Europe et conserver la correction. Ne jamais transposer une dose entre indications ou produits. Un état de surveillance n’est pas une preuve de production ; mettre à jour le checkpoint avec les fichiers réellement présents.
