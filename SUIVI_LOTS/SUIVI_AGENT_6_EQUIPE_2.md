1. Tunder remplace ☐ par ☑ dans la colonne « Terminé » quand le fichier Partie 3 du LOT est réellement déposé dans le sous-dossier Drive LOT_X de « LOTS_Finaux avec statut » (taille vérifiée). Jamais pour un fichier inachevé ; une étape non vérifiée est notée « NON VÉRIFIÉ » et la case reste ☐.

3. Note brève et précise, par exemple « LOT_240 Partie 3 déposée ».
4. Où chercher : lien Drive du fichier, puis branche `lot/LOT_X` après la resynchronisation GitHub (faite par Tunder quand les cinq fichiers V7 du LOT sont présents).
5. Aucune ligne n'est supprimée.
6. En fin de série, Tunder ouvre l'issue `[FIN DE SÉRIE] Agent 6 — LOT_240–248 · Partie 3` avec la seule étiquette `fin-de-serie` — **jamais `audit-ok`**, qui déclenche la fusion automatique vers `main` — puis inscrit « Oui + lien de l'issue » dans la colonne « Signal GitHub ».
7. Le chat avec l'utilisateur sert uniquement aux trois cas de la règle n° 1 ; il ne remplace ni la coche ni le signal GitHub.
