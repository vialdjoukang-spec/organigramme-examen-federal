# Réservation G9 · causes ciblées du prurit

Rédaction et audit séquentiels par Codex, modèle courant de secours (Luna CLI indisponible).

Lot réservé : xérose du sujet âgé, prurit urémique, prurit ferriprive, prurit médicamenteux, prurits neuropathiques et prurit psychogène. Les autres diagnostics de G9 ne sont pas déclarés traités.

Source principale à appliquer : Weisshaar et al., recommandation européenne EDF, Acta Dermato-Venereologica 2025, DOI 10.2340/actadv.v105.44220. Texte intégral officiel accessible ; sections pertinentes et tableaux relus dans le dossier de sources hors git. Les posologies du guide ne remplacent pas la lecture AIPS.

Cette réservation ne livre aucune monographie complète. Le lot suivra #64 dans la chaîne Hygie ; aucune fusion avant ce prédécesseur, l’audit du lot et les contrôles requis. Les quatre attentes R13 existantes sont conservées.
