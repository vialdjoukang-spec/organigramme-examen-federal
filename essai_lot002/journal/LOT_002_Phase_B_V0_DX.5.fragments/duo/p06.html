L'examinateur cherche d'abord le normal : les ganglions mesurent moins de 1 cm et restent mous, mobiles, indolores.8

  • Général : Recherche : L'examinateur mesure la température tympanique ou orale. Valeur : La fièvre dépasse 38 °C en phase aiguë.
  • Tête et cou : Recherche : L'examinateur palpe en mouvements circulaires les chaînes cervicales, sus-claviculaires, axillaires et inguinales. Valeur : Un ganglion de plus de 1 cm est anormal. ; Recherche : L'examinateur abaisse la langue et éclaire l'oropharynx. Valeur : L'exsudat est net dans l'EBV et discret dans le CMV (DX.6).
  • Thorax : Recherche : L'examinateur ausculte les bases, le patient respirant profondément. Valeur : Les crépitants évoquent une pneumonite.
  • Abdomen : Recherche : L'examinateur palpe sous le rebord costal gauche, le patient inspirant profondément, sans brutalité. Valeur : Un bord palpable signe une rate augmentée, à risque de rupture. ; Recherche : L'examinateur percute puis palpe le foie sous le rebord costal droit. Valeur : Une flèche hépatique supérieure à 12 cm est anormale.
  • Peau : Recherche : L'examinateur inspecte le tronc et les membres. Valeur : L'amoxicilline provoque un exanthème chez plus de 90 % des mononucléoses.
  • Yeux et neurologie : Recherche : L'examinateur pratique un fond d'œil. Valeur : Des foyers hémorragiques évoquent une rétinite. ; Recherche : L'examinateur teste les réflexes rotulien et achilléen. Valeur : Une aréflexie avec faiblesse ascendante évoque un Guillain-Barré.
