Un ganglion normal mesure moins de 1 cm ; il est souple, mobile et indolore. L'examinateur compare les deux côtés.
  • Cou : Recherche : Le patient est assis ; l'examinateur, derrière lui, palpe le creux sus-claviculaire en inspiration profonde. Valeur : Un ganglion évoque un cancer thoracique ou abdominal ; à gauche, c'est le ganglion de Virchow.
  • Coude : Recherche : Le coude est fléchi à 90° ; l'examinateur palpe le creux du coude. Valeur : Au-delà de 0,5 cm, il est pathologique (syphilis, lymphome).
  • Abdomen : Recherche : Le patient inspire ; la main en crochet cherche la rate sous le rebord costal gauche. Valeur : Elle évoque mononucléose, lymphome ou leucémie.
  • Aine : Recherche : L'examinateur palpe l'aine, puis explore les jambes et le périnée. Valeur : Jusqu'à 1,5 cm, il peut être normal.
  • Ganglion : Recherche : L'examinateur mesure le plus grand diamètre, puis déplace le ganglion sur le plan profond. Valeur : Plus de 1 cm est anormal1, plus de 2 cm suspect ; la fixation ou la confluence évoque une malignité (rapport de cotes 6,18)3.
