Étape 2 : sans urgence, progresser en six temps.
  • Le médecin décrit le ganglion : taille, consistance, mobilité, douleur, peau.
  • Il classe l'adénopathie en localisée ou généralisée.
  • Il cherche la porte d'entrée dans le territoire de drainage.
  • Il interroge les expositions : chat, aliments, voyage, contage, rapports sexuels, médicaments.
  • Il demande le bilan de première intention orienté.
  • Il observe 4 semaines si le tableau est bénin ; au-delà, échographie puis biopsie-exérèse1.

Le diagnostic différentiel dangereux s'ouvre dans une fenêtre :

  • DX.2 Lymphome : histologie du ganglion entier ; la cytoponction peut échouer et un corticoïde préalable masque la maladie.
  • DX.11 Sus-claviculaire : TDM thoraco-abdominale puis biopsie ; à gauche, le ganglion de Virchow signale un cancer abdominal.
  • DX.12 Tuberculose : PCR et culture du ganglion ; un IGRA négatif n'exclut pas la maladie.
  • DX.13 VIH : test combiné de 4e génération ; en fenêtre sérologique, répéter ou doser la charge virale.
  • DX.14 Syphilis : sérologies tréponémique et non tréponémique ; l'éruption palmo-plantaire non prurigineuse passe pour une virose.
  • DX.15 Kawasaki : fièvre de 5 jours ou plus, 4 critères sur 5, échographie cardiaque ; forme incomplète chez le nourrisson.
