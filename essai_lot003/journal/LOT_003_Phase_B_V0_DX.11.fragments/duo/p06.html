• État général : Recherche : Le médecin pèse le patient et inspecte les muqueuses. Valeur : Elle oriente vers une déshydratation. Recherche : Le médecin demande une collecte sur 24 heures. Valeur : Au-delà de 50 mL/kg, la polyurie est confirmée.
  • Hémodynamique : Recherche : Le médecin mesure la pression couché, puis debout. Valeur : Elle évoque une déshydratation.
  • Neurologique : Recherche : Le médecin évalue l'orientation. Valeur : Elle signe une hypernatrémie grave.
  • Vision : Recherche : Le médecin compare le champ du patient au sien. Valeur : Une hémianopsie bitemporale évoque une masse suprasellaire.
  • Signes endocriniens : Recherche : Le médecin inspecte peau et pilosité. Valeur : Ils orientent vers un hypopituitarisme.
