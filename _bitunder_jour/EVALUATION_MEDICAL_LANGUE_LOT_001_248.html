Méthodologie (formules)

Priorité des méthodes. 1) AUDITEUR si scores d'audit réels existent pour ≥ 5 leçons du LOT ; 2) sinon HEURISTIQUE sur les HTML disponibles (source la plus complète ; à égalité, version V0 récente Claude/Codex/Grok avant Archive) ; 3) sinon ABSENT (null, jamais 0).

AUDITEUR

LOT_001–012. Dernier cycle (C7) des contrôles harnais : MED_* (contrôle médical d'ancrage : doses AIPS, PMID, chiffres retrouvés dans la source) = Médical ; CONF_* (contrôle de langue) = Linguistique. Moyenne pondérée par la taille (octets) de chaque leçon.
LOT_013–017. RAPPORT_QUALITE.json, scores « après » dernière passe (auditeur-medical opus + auditeur-conformite), moyenne pondérée par octets. LOT_017 : 1 seule leçon auditée → HEURISTIQUE retenue, audit partiel affiché.
Auto-audit. LOT_134–135 : scores.jsonl rédigés par l'auditeur du même modèle que le rédacteur (Grok) → étiqueté AUDITEUR (auto), non indépendant.

HEURISTIQUE — Linguistique

Par fichier : L = 100 − [min(25 ; 3·PL) + min(10 ; 3·PV) + min(20 ; 3·SG) + min(8 ; 2·AB) + min(10 ; 2·DB) + min(7 ; 0,1·NB) + min(5 ; 0,5·EP) + min(10 ; 2,5·ST)], où PL = phrases > 35 mots, PV = phrases à ≥ 2 points-virgules et > 20 mots, SG = sigles non développés à la 1re occurrence, DB = phrases ≥ 8 mots répétées, NB = espaces insécables manquantes, EP = espaces avant . ou , (tous pour 1000 mots audités) ; AB = types d'abréviations interdites ; ST = défauts de structure (DOCTYPE, FIN_FICHIER, balises déséquilibrées, title=, script).
