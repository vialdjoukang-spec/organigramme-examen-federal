Carence en folates

Taille : en cours de mesure

F1.17 · DX.8 · Carence en folates

L'essentiel

AIPS (information professionnelle suisse du corpus local) est le sens utilisé ici. CAT (conduite à tenir) est le sens utilisé ici. NFS (numération formule sanguine) est le sens utilisé ici. VGM (volume globulaire moyen) est le sens utilisé ici. OMS (organisation mondiale de la santé) est le sens utilisé ici. CRP (protéine C réactive) est le sens utilisé ici. LDH (lactate déshydrogénase) est le sens utilisé ici. SSP (situation du référentiel suisse) est le sens utilisé ici. HUG (hôpitaux universitaires de Genève) est le sens utilisé ici. NICE (institut britannique pour l'excellence clinique) est le sens utilisé ici. UKKA (association britannique du rein) est le sens utilisé ici. OFS (office fédéral de la statistique) est le sens utilisé ici. Alimentation pauvre ou alcool. On écarte la vitamine avant les folates seuls. Le comprimé suisse lu fait cinq milligrammes.

La démarche juge l'hémodynamique avant le fer et avant l'endoscopie.

Détail 4.1

On le dit avec des mots simples : deux mécanismes seulement : moins d'hémoglobine, ou moins de débit cutané.1

On ne mélange pas ce constat avec le diagnostic voisin : chez l'homme adulte, le plan retient une hémoglobine basse sous 130 g/l.11

Détail 4.2

En pratique, pour Carence en folates, les schémas sont des dessins, aucune image n'est injectée.12

On le dit avec des mots simples : sous antiépileptique, on surveille les concentrations de l'anticonvulsivant.8
