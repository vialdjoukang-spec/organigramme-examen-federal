L'essentiel

AIPS (information professionnelle suisse du corpus local) est le sens utilisé ici. CAT (conduite à tenir) est le sens utilisé ici. NFS (numération formule sanguine) est le sens utilisé ici. VGM (volume globulaire moyen) est le sens utilisé ici. OMS (organisation mondiale de la santé) est le sens utilisé ici. CRP (protéine C réactive) est le sens utilisé ici. LDH (lactate déshydrogénase) est le sens utilisé ici. SSP (situation du référentiel suisse) est le sens utilisé ici. HUG (hôpitaux universitaires de Genève) est le sens utilisé ici. NICE (institut britannique pour l'excellence clinique) est le sens utilisé ici. UKKA (association britannique du rein) est le sens utilisé ici. OFS (office fédéral de la statistique) est le sens utilisé ici. Microcytose ancienne et familiale, ferritine non basse. Le fer oral est contre-indiqué dans la thalassémie.

Détail 4.1

On le dit avec des mots simples : deux mécanismes seulement : moins d'hémoglobine, ou moins de débit cutané.1

On ne mélange pas ce constat avec le diagnostic voisin : chez l'homme adulte, le plan retient une hémoglobine basse sous 130 g/l.11

Détail 4.2

En pratique, pour Thalassémie mineure, les schémas sont des dessins, aucune image n'est injectée.12

On le dit avec des mots simples : les comprimés ne sont pas recommandés avant 12 ans.5
