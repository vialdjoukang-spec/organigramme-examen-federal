1040 participants recrutés par 14 centres dans 6 pays européens, de février 2014 à septembre 2015.
Syndrome de Turner n = 301 ; 45,X/46,XY n = 45 ; syndrome de Klinefelter n = 218 ; dysgénésie gonadique 46,XY/ovotestis n = 63 ; insensibilité complète aux androgènes n = 71 ; insensibilité partielle n = 35 ; défauts de synthèse des androgènes n = 20 ; hypospadias sévère n = 25 ; HCS 46,XX n = 226 ; dysgénésie 46,XX n = 21.
Incidences rappelées : HCS 1 sur 15 000 ; anomalies génitales 1 sur 4 500.
