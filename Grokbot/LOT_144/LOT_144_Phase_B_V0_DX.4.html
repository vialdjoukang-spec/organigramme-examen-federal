Hémorragie intracérébrale spontanée

Taille : en cours de mesure

F1.15 · DX.4 · Hémorragie intracérébrale spontanée

L'essentiel

AIPS (information professionnelle suisse du corpus local) est le sens utilisé ici. CAT (conduite à tenir) est le sens utilisé ici. TDM (tomodensitométrie) est le sens utilisé ici. EEG (électroencéphalogramme) est le sens utilisé ici. IRM (imagerie par résonance magnétique) est le sens utilisé ici. FOUR (score de réactivité en quatre volets, utilisable si la personne est intubée) est le sens utilisé ici. AVC (accident vasculaire cérébral) est le sens utilisé ici. HSA (hémorragie sous-arachnoïdienne) est le sens utilisé ici. SSP (situation du référentiel suisse) est le sens utilisé ici. Début brutal, déficit, vigilance qui chute. Scanner sans injection. L'engagement se voit à la pupille. Pas de ponction si la masse pousse.
